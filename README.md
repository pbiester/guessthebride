# Guess the Bride 🥂 - Hochzeitsspiel

Ein elegantes, webbasiertes Hochzeitsspiel, bei dem Gäste raten können, welche Person welches Brautkleid trägt. Die Ergebnisse werden in Echtzeit in ein Google Sheet übertragen.

## ✨ Features

- **Elegantes Design:** Optimiert für mobile Endgeräte im festlichen Hochzeits-Look.
- **1:1 Zuordnung:** Intelligente Matrix-Logik verhindert, dass eine Person mehreren Kleidern zugeordnet wird.
- **Namens-Check:** Prüft im Hintergrund, ob unter einem Namen bereits Tipps abgegeben wurden, um Dopplungen zu vermeiden.
- **Google Sheets Anbindung:** Automatisches Speichern aller Tipps inklusive Zeitstempel.
- **Passwortschutz:** Zugriffsschutz über einfache URL-Parameter (`?p=...`).
